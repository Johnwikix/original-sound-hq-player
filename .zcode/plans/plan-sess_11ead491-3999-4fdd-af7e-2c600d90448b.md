## UpdateHistoryDialog 添加 RTSS 不兼容提醒

### 目标
在 `UpdateHistoryDialog` 中加一个独立的、固定的常驻提醒区域（不是更新条目），告知用户：本程序与 RivaTuner Statistics Server (RTSS) 不兼容。原因是 RTSS 的 DXGI 注入会在桌面歌词和着色器背景同时启用时，与两个 Win2D `CanvasAnimatedControl` 的渲染线程冲突并触发崩溃。

### 修改的文件（3 个）

#### 1. `D:\code\winui\music_player\View\SubView\UpdateHistoryDialog.xaml`
- 把 `Grid` 的行定义从 `RowDefinitions="Auto,*,Auto"`（3 行）改成 `RowDefinitions="Auto,Auto,*,Auto"`（4 行）。
- 在新插入的第 0 行放一个固定的警告 `Border`（浅红边/浅红底，左侧 ⚠ 图标 + 标题 + 详细说明两行文字）。
- `ScrollViewer`（更新内容区）下移到第 2 行。
- 底部链接区保持第 3 行不变。
- 标题与说明使用 `x:Name` + code-behind 赋值，避免 `x:Uid` 在多语 `.resw` 中漏 key 时整段缺失（沿用项目里 `ToolUtils.GetString` 的模式）。

#### 2. `D:\code\winui\music_player\View\SubView\UpdateHistoryDialog.xaml.cs`
- 构造函数末尾追加两行：
  - `RtssWarningTitle.Text = ToolUtils.GetString("RtssWarningTitle");`
  - `RtssWarningBody.Text = ToolUtils.GetString("RtssWarningBody");`

#### 3. `D:\code\winui\music_player\Strings\zh-CN\Resources.resw` 和 `D:\code\winui\music_player\Strings\en\Resources.resw`
- 末尾追加两条 key：
  - `RtssWarningTitle`
    - zh-CN: `与 RivaTuner Statistics Server (RTSS) 不兼容`
    - en: `Incompatible with RivaTuner Statistics Server (RTSS)`
  - `RtssWarningBody`
    - zh-CN: `RTSS 通过 DXGI 注入替换 swap chain。当「桌面歌词」与「着色器背景」同时启用时，两个 Win2D 渲染线程并发呈现会与 RTSS 钩子冲突，可能导致程序崩溃。请在使用本程序前关闭 RTSS / MSI Afterburner 的挂钩。`
    - en: `RTSS hooks the DXGI swap chain. When "Desktop Lyrics" and the shader background are both enabled, two Win2D swap chains run concurrently and can crash the app under RTSS injection. Please disable RTSS / MSI Afterburner hooks before using this player.`
- 其他语言 (de/es / ru/ja) 不动 —— `ToolUtils.GetString` 在缺失 key 时回退到 key 名，不会崩溃。

### 关键决策
- **不进 `UpdateNotes.json`**：用户明确说这是常驻提醒而非更新条目；`UpdateNotes.json` 每次版本发布会被覆盖，警告应当一直显示。
- **位置选顶部**：用户每次版本更新都会看这条提醒，放顶部视觉权重最高。
- **不动 `UpdateNotes.json` / `UpdateNotes.cs` / `UpdateNotesJsonContext.cs` / `AppInitializerService.cs` / 链接区**。

### 不做的事（已与用户对齐）
- 不做 RTSS 检测 / 模块枚举。
- 不做自动降级到 `TextBlockLyricsRenderer`。
- 不修改现有 3 条更新条目。

### 验收
- 启动应用 → 弹出 `UpdateHistoryDialog` → 顶部出现红色边框警告「与 RTSS 不兼容」+ 详细说明；下方仍能滚动显示 3 条更新内容；底部链接区不变。
- 中英文 UI 切换时警告文字跟随切换（zh-CN / en `.resw` 已添加）。
- 不破坏 `UpdateNotes.json` 的解析与显示。
