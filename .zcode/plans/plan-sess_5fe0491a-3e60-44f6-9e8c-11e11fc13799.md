# FFmpeg 转换时内联写入元信息（标签/封面/歌词），消除转换后 ATL 整文件重写

## 动机与收益
现状：转换完成后 `SaveMetaDataAsync` 用 ATL 重写整个输出文件（标签/封面/歌词）。大文件（DSF→m4a 40MB）重写耗时数秒——它既是**双倍 IO**，也是此前"文件占用"竞态的根源。FFmpeg 原生支持在 `avformat_write_header` 时写入元数据：**一次写盘完成全部内容**，从根上消除这类竞态与双写。

## FFmpeg 能力地图（执行第一步先用 CLI 实验逐一验证）
- **基本标签**（title/artist/album/track/disc/date）：`av_dict_set` 写输出上下文 metadata，全部 8 格式通用 ✓
- **封面**：mp3（ID3v2 APIC）/ flac（PICTURE 块）/ m4a·ipod（covr atom）= 附加图片流 + `attached_pic` disposition + 单包直通（codec 从图片签名判 MJPEG/PNG）；ogg/opus = vorbis comment `METADATA_BLOCK_PICTURE`（C# 构造 FLAC picture block + base64，约 40 行）；**wma/asf：muxer 不支持 → 保留 ATL 回退**
- **歌词**：flac/ogg/opus = `LYRICS` vorbis comment ✓；mp3/m4a 验证 `lyrics` 键映射（USLT/©lyr）；wma 验证，失败则回退

## 实施步骤

### 第一步：CLI 验证实验（临时目录，验证后清理）
用 ffmpeg CLI 对 6 种容器逐个写 `标签+lyrics 元数据+attached_pic 封面`，ffprobe 读回 `format_tags`/streams 确认每个格式的真实映射；据此填写能力表 `FFmpegMetadataSupport`（Tags/Cover/Lyrics 三列布尔）。结果决定 ATL 回退面（预期仅 wma）。

### 第二步：FFmpegAudioConverter 内联元数据
- `Convert(...)` 增加 `ConversionMetadata?` 参数（Title/Artist/Album/TrackNumber/DiscNumber/Year/CoverBytes/CoverMime/Lyrics）
- 基本标签 + 歌词：`av_dict_set` 到输出上下文/流 metadata
- 封面（mp3/flac/m4a）：创建附加图片流（codecpar 按 JPEG/PNG 签名设 MJPEG/PNG），`write_header` 后、音频包前写入单包，disposition=attached_pic
- 封面（ogg/opus）：构造 FLAC picture block → base64 → `METADATA_BLOCK_PICTURE` comment
- 失败容忍：元数据写入异常不回滚转换（记日志），保持输出可用

### 第三步：服务层重构
- `ConversionMetadata` 记录（Model）；歌词/封面**提前**获取（`GetLyricsAsync` + `ToolUtils.GetRawImage`）
- `AudioConverterService`：能力表查询——全支持格式 → 转换内联写完即止（删除后置 ATL）；wma 等回退格式 → 转换后仍走 ATL（门保持到回退完成）。`ConvertForExportAsync`（USB）同构改造
- 删除 `SaveMetaDataAsync` 常规路径（仅回退路径保留私有版本）

### 第四步：回归验证
1. harness：8 格式 × 真实 DSF，转换后 **ffprobe**（format_tags/streams）与 **ATL Track**（Title/EmbeddedPictures/Lyrics）双向读回校验——确保音乐库读取端看到的元数据与旧路径等价
2. 歌词多行/空歌词/无封面/无歌词边界用例
3. 主程序 Debug/Release 构建 0 错误

## 涉及文件
`AudioConverters/FFmpegAudioConverter.cs`（+约 200 行元数据写入）、`Services/AudioConverterService.cs`（流程重构）、`Model/ConversionMetadata.cs`（新）、harness（临时）

## 说明
- ATL 依赖不移除（回退路径 + 音乐库读取仍用）
- 封面图片字节直接 passthrough 不重编码；faststart 与封面兼容（CLI 同款做法）
- 若 CLI 验证发现 mp3/m4a 歌词映射不可用，回退面相应扩大（能力表驱动，结构不变）
