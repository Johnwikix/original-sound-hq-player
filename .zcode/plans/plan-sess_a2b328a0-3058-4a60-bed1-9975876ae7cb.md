# AdvanceLyricsCanvasControl：描边宽度/字重宿主覆盖能力

## 调查结论
- **描边**：渲染链路已预留（`StrokeWidth` → `EnsureCaches` 用 `CanvasGeometry` + 圆角 `DrawGeometry` 画描边，颜色经 Tint 跟随歌词色，`StrokeWidth > 0` 即开启）但**当前实际无效**——主程序发布 `strokeWidth: 0.0` 写死、coordinator 布局调用 `MeasureAndArrange(..., 0)` 写死 → `RecreateTextGeometry` 永不执行 → 几何体不存在 → 描边分支永远画空。
- **字重**：`LyricsLayoutManager.MeasureAndArrange` 共享格式与 `RenderLyricsLine.RecreateTextLayout` 回退格式均硬编码 `FontWeight(700)`，不可配置。

## 修改（全部在 External\AnimatedWin2dControls，调用点唯一）
1. **`LyricsRenderCoordinator`**：
   - 新增 `int? FontWeightOverride` / `double? StrokeWidthOverride` 宿主覆盖属性（null = 跟随总线）+ `InvalidateStyle()`（`_layoutDirty = true; Canvas?.Invalidate()`）。
   - 两处消费点改为取"覆盖优先"：布局调用传 `effectiveStrokeWidth = (int)(StrokeWidthOverride ?? _cachedStrokeWidth)` 与 `fontWeight = FontWeightOverride ?? 700`；`EnsureCaches(sender, StrokeWidthOverride ?? _cachedStrokeWidth)`。宽度变化经 `InvalidateStyle` → 重排 → `DisposeCaches` → 重建描边缓存。
2. **`LyricsLayoutManager.MeasureAndArrange`**：+`int fontWeight = 700` 参数，`shareFormat.FontWeight` 使用之。
3. **`RenderLyricsLine.RecreateTextLayout`**：+`int fontWeight = 700` 参数（回退 format 使用）。
4. **`AdvanceLyricsCanvasControl`**：+`FontWeightOverride`/`StrokeWidthOverride` 包装属性（→ coordinator + `InvalidateStyle()`）。

主程序零改动；未来 `AdvanceLyricsRenderer.SetStyle` 直接映射：`StrokeWidthOverride = style.Outline ? style.OutlineWidth : 0`、`FontWeightOverride = style.FontWeight`。

## 验证
`dotnet build` 0 错误（External 库随主项目编译）；现有主窗口歌词行为不变（Override 默认 null）。
