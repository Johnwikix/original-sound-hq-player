# 桌面歌词第五轮修复

## 1. 持久化时机简化（去掉防抖定时器）
- 删除 `_boundsPersistTimer` / `ScheduleBoundsPersist` / `OnBoundsPersistTick` / `BoundsPersistDelayMs`。
- `OnAppWindowChanged` 仅更新内存中的 `BoundsState`（不落盘）。
- 落盘点只剩三处：**窗口 Closed**（关闭按钮/托盘开关/退出关窗都会触发）调 `PersistBounds()`；**`ApplyDefaultBounds()`**（重置按钮建立 HasBounds）调 `PersistBounds()`；**`Manager.Shutdown()`** 已有的 `PersistBounds()`（应用退出兜底，同步写）。

## 2. 边框：按你的建议改为"基本窗口 + spectrum 原样方法"
嫌疑确认：`ConfigureWindow` 里的 `presenter.SetBorderAndTitleBar(true, false)` / `IsMinimizable/IsMaximizable/IsResizable` 裁剪掉了系统标题栏按钮，presenter 由此进入自定义框架状态，与 GWL_STYLE 的 `WS_POPUP` 切换冲突 → 锁定时顶部框变粗。spectrum 的窗口从未碰过这些 API。

- `ConfigureWindow` 只保留 `presenter.IsAlwaysOnTop = true` 与 `IsShownInSwitchers = false`，**删除全部 presenter 标题栏/按钮裁剪**。窗口成为标准窗口：解锁态 = 带系统标题栏（min/max/close）+ 可拖动（标题栏或按住内容区）+ 可调整大小（边缘）；锁定态 = 切 WS_POPUP 后完全无边框。
- `ApplyLock` 改为 **spectrum 原样单步**：首次锁定缓存 `GetWindowStyle()`，然后只调 `ToggleWindowStyle(true, WindowStyle.Popup | WindowStyle.Visible)`（去掉上一轮自加的 AND-NOT Caption|ThickFrame 步骤）；解锁 `SetWindowStyle(缓存样式)` 还原。

## 3. 验证
构建 0 错误。用户侧：锁定后无边框且点击穿透（悬停按钮组可解锁）；解锁态出现标准标题栏属预期（与 spectrum 解锁态一致），确认锁定无边框生效后如需"无标题栏的解锁态"再另行迭代。
