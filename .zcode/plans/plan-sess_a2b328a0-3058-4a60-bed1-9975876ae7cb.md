# 桌面歌词交互优化（合并两轮反馈）

## 1. 默认不锁定
`Model\SaveSettings.cs`、`Model\AppSettings.cs`：`IsDesktopLyricsLocked` 默认 `true` → `false`。

## 2. 默认尺寸翻倍
`DesktopLyricsWindow.xaml.cs`：`DefaultWidth 900→1800`、`DefaultHeight 140→280`。

## 3. 拖动改为手动实现（修复"点击切换状态、按住拖不动"）
根因：`PointerPressed` 内同步发 `WM_NCLBUTTONDOWN/HTCAPTION` 与 XAML 指针捕获栈冲突。改为纯手动拖动，语义即"按住拖动"：
- `PointerPressed`（解锁态、左键）：`GetCursorPos` 记录起始物理坐标 + `AppWindow.Position` 记录起始窗口位置，`RootGrid.CapturePointer`。
- `PointerMoved`：按游标增量 `AppWindow.Move(起点窗口位置 + delta)`（GetCursorPos 与 AppWindow.Position 均为物理像素，无 DPI 换算问题）。
- `PointerReleased/Canceled/CaptureLost`：结束并 `ReleasePointerCapture`。
- 删除 `WM_NCLBUTTONDOWN/HTCAPTION/ReleaseCapture` 相关常量与 P/Invoke。`AppWindow.Changed` 的位置持久化逻辑不变。
- XAML 根 Grid 增加 `PointerMoved/PointerReleased/PointerCanceled/PointerCaptureLost` 挂钩。
- 按钮（ButtonBase 自行处理 PointerPressed 且标记 Handled）不会触发拖动，无需额外排除。

## 4. 锁定时隐藏窗口边框
`ApplyLock` 重构：锁定 → `presenter.SetBorderAndTitleBar(false, false)`（完全无边框）；解锁 → `SetBorderAndTitleBar(true, false)` + `IsResizable=true`。穿透位操作抽成带状态跟踪的 `ApplyClickThrough(bool)`。

## 5. 歌词窗口右上角按钮组（锁定 + 关闭）
- XAML：右上角水平 `StackPanel ControlPanel`，含：
  - `LockButton`：28×28 圆形半透明、FontIcon E72E，Click → `DesktopLyricsManager.SetLocked(!IsLocked)`；
  - `CloseButton`：同款、FontIcon E711（×），Click → `DesktopLyricsManager.SetEnabled(false)`（持久关闭，可经播放条/托盘再开）。
- 悬停穿透（BetterLyrics `OverlayInputHelper` 方案）：锁定时 50ms `DispatcherQueueTimer` 轮询，`GetCursorPos`+`ClientToScreen(hwnd)`+`TransformToVisual(null)`×`RasterizationScale`（外扩 6px）判定游标是否在 `ControlPanel` 上：在 → 临时取消穿透并显示按钮组；离开 → 恢复穿透并隐藏；解锁时停轮询、按钮组常显。判定目标由 LockButton 改为整个 ControlPanel。
- 新增 P/Invoke：`GetCursorPos`、`ClientToScreen`（POINT 结构）；`OnWindowClosed` 停止轮询定时器。

## 6. 主界面播放条右侧入口按钮
- `View\MainPage.xaml`：Column=2 StackPanel 内 `EqualizerButton` 之后加 `DesktopLyricsButton`（`MenuButtonStyle`、透明背景、`Margin="10,0,0,0"`、`Glyph="&#xE8C1;"`、图标 `Opacity=0.4` 表示关闭态）。
- `View\MainPage.xaml.cs`：ctor 订阅 `DesktopLyricsManager.StateChanged` 同步图标透明度（开=1.0/关=0.4）；Click → `SetEnabled(!IsEnabled)`。
