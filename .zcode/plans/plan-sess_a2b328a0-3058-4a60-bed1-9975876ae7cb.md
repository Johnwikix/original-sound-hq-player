# 桌面歌词功能实现计划

## 架构总览

新增独立 `DesktopLyrics/` 文件夹，**不改现有歌词管线和播放框架**，数据全部来自现有静态消息总线（`AnimatedWin2dControls.Messages`，与 `SimpleLyricsControl` 完全同构）：

- `UILyricsBus.Changed` → 歌词列表（换歌）
- `TimeProgressBus.CurrentPlayingTimeChanged(long)`（UI 线程 125ms tick）→ 当前行判定
- `OffsetMsBus` / `IsPlayingBus` / `LyricsFontSizeBus` / `LyricsSettingsBus` → 偏移、样式
- `LyricsSyncRequestBus.Request()` → 初始化时拉全量状态

窗口行为参考 BetterLyrics `NowPlayingWindow` Desktop 模式：透明 SystemBackdrop、无边框、置顶、不进任务栏/Alt-Tab、不抢焦点（不 Activate）；锁定 = `GWL_EXSTYLE |= WS_EX_LAYERED|WS_EX_TRANSPARENT` 完全点击穿透，解锁按钮放在托盘 `NotifyIconControl` 菜单（锁定态统一走托盘解锁，不做悬停按钮）。

**逐字效果预留接口**：定义 `IDesktopLyricsRenderer`，当前实现为 `TextBlockLyricsRenderer`；未来 `AdvanceLyricsRenderer` 直接包装现有 `AdvanceLyricsCanvasControl`（该控件 Loaded 时经 `LyricsRenderCoordinator.Attach()` 自同步全部总线，接入成本≈0，无需改任何已有代码）。

## 新增文件（`WinUIMusicPlayer/DesktopLyrics/`，SDK 风格自动包含，无需改 csproj）

1. **`TransparentTintBackdrop.cs`** — `SystemBackdrop` 派生类，`OnTargetConnected` 中 `connectedTarget.SystemBackdrop = compositor.CreateColorBrush(Colors.Transparent)`（与现有 `Helper\CustomAcrylicSystemBackdrop` 同模式）。

2. **`IDesktopLyricsRenderer.cs`** — 逐字预留接口：
   ```csharp
   public interface IDesktopLyricsRenderer : IDisposable
   {
       UIElement Content { get; }
       void SetLyrics(IList<LyricLine>? lyrics);
       void SetPlaybackTime(long totalMs);
       void SetOffset(double offsetMs);
       void SetIsPlaying(bool isPlaying);
   }
   ```

3. **`TextBlockLyricsRenderer.cs`** — 实现 `IDesktopLyricsRenderer`。自订阅上述总线（ctor 订阅 + `LyricsSyncRequestBus.Request()`，Dispose 退订，模式照抄 `SimpleLyricsControl`）。当前行二分查找 `FindCurrentLineIndex` 与 `ConcatWords` 从 `SimpleLyricsControl.xaml.cs:297/361` 复制（私有方法无法复用）。视觉：Grid 双层文本（黑色阴影层偏移 2px + 白色主层）+ 翻译行（`TransLateText`，字号 0.75×，仅在有翻译时显示），居中；字号 = `LyricsFontSizeBus` 值 × 0.8、字体跟随 `LyricsSettingsBus.FontFamilyName`、启用自定义色时用 `LyricsCustomColor`（全部来自总线，零新增设置项）。

4. **`DesktopLyricsWindow.xaml/.cs`** — 透明置顶窗口：
   - 构造：`SystemBackdrop = new TransparentTintBackdrop()`；`OverlappedPresenter.SetBorderAndTitleBar(true, false)` + `IsResizable = true` + `IsAlwaysOnTop = true`；`AppWindow.IsShownInSwitchers = false`；默认 900×140，位置 = 设置值或主屏工作区底部居中（恢复时经 `WindowSizeHelper.IsBoundsOnScreen` 校验）；`AppWindow.Show(activateWindow: false)` 不抢焦点。**不套 ThemeStyleHelper**（保持透明）。
   - 内容：根 `Grid`（`Background="Transparent"`，Padding=8，可点击）+ `ContentPresenter` 承载渲染器。
   - **锁定/解锁** `ApplyLock(bool)`：经现有 `WindowHelper.SetWindowLongPtr` 增删 `WS_EX_LAYERED|WS_EX_TRANSPARENT`（GWL_EXSTYLE=-20 与 WS_EX_ 常量在文件内本地定义）；锁定时 `IsResizable=false`。
   - **拖动**：根 Grid `PointerPressed` → `ReleaseCapture()` + `SendMessage(hwnd, WM_NCLBUTTONDOWN=0xA1, HTCAPTION=0x2, 0)`（ReleaseCapture 需新增一条小型 `[LibraryImport]`，SendMessage 用现有 WindowHelper）。
   - **位置记忆**：`AppWindow.Changed` 中非拖动中间态写回 `AppSettings.DesktopLyricsX/Y`（内存），关窗/锁定/退出时随设置落盘。
   - Dispose 时释放渲染器。

5. **`DesktopLyricsManager.cs`** — 静态生命周期管理（风格同静态总线）：
   - `IsEnabled` / `IsLocked` 属性 + `StateChanged` 事件（托盘勾选态同步用）
   - `SetEnabled(bool)`：创建/关闭窗口并持久化；`SetLocked(bool)`：调窗口 `ApplyLock` 并持久化
   - `RestoreFromSettings()`：启动恢复；`Shutdown()`：保存位置+关窗+清理
   - 持久化调用 `App.Services.GetRequiredService<MusicDatabaseService>().SaveSettingAsync()`（沿用 VM 属性落盘模式）

## 运行时数据流

AppViewModel 125ms tick → `TimeProgressBus` → `TextBlockLyricsRenderer` 二分定位当前行 → 行变更时更新主文本 + 翻译。双窗口同处一个 UI 线程，总线事件无需跨线程调度（与 SimpleLyricsControl 相同假设）。AppViewModel/播放/IPC 层零改动。

## 明确不做（保持简单）

- 不做逐字卡拉OK渲染（接口已预留，未来把 `AdvanceLyricsCanvasControl` 包成 `AdvanceLyricsRenderer` 即可）
- 不做设置页 UI（开关/锁定仅托盘；位置/状态自动记忆）
- 不做 OverlayInputHelper 悬停解锁、全局热键
- 不做行点击跳转播放

## 注意事项

- WinUI 3 透明窗口 = 透明 SystemBackdrop + 无标题栏，WindowsAppSDK 2.4 下 `OverlappedPresenter` 各 API 可用；`PublishTrimmed` 下 SystemBackdrop 派生类与现有 Custom*Backdrop 同模式、无裁剪风险。
- 默认锁定 + 完全穿透，不会挡住桌面操作；解锁后整个窗口区域可拖拽（透明区也命中，符合桌面歌词习惯）。
- 构建验证：`dotnet build` WinUIMusicPlayer.csproj（Debug, x64），XAML 编译错误会在此暴露。
