# 桌面歌词第三轮优化

## 1. 边框修复（spectrum / BL 同源方案）
music_player 已引用 WinUIEx 2.9.3，直接用 spectrum 同款窗口样式扩展（内部 `GWL_STYLE` + `SetWindowPos(SWP_FRAMECHANGED)` 立即重算，解决"边框不消失/resize 后样式怪异"）：
- `ApplyLock` 重写：锁定时缓存原始样式（`GetWindowStyle()`，仅首次）→ `ToggleWindowStyle(WindowStyle.Caption | WindowStyle.ThickFrame, false)` 移除标题栏与可调边框；解锁时 `SetWindowStyle(缓存的原始样式)` 还原。删除原 `presenter.SetBorderAndTitleBar/IsResizable` 切换（与 GWL_STYLE 冲突的根源）。
- ctor 的 `SetBorderAndTitleBar(true, false)` 基线保留（解锁态=有边框无标题栏、可调整大小）。

## 2. 位置 + 大小持久化（多显示器）
- `SaveSettings`/`AppSettings` 新增 `DesktopLyricsWidth/Height`（默认 1800/280）；`MusicDatabaseService` 两侧映射（+2 行）。
- `OnAppWindowChanged`：`DidSizeChange` 时记录 `sender.Size` 到 AppSettings（位置记录已有）。
- `ConfigureWindow`：恢复 X/Y/W/H 四元组，`IsBoundsOnScreen` 校验（其内部 `DisplayArea.FindAll()` 已覆盖多显示器），失败回退默认尺寸 + 主屏工作区底部居中。

## 3. 重置窗口按钮（窗口 + 托盘）
- 新增 `DesktopLyricsManager.ResetWindowBounds()`：调窗口 `ApplyDefaultBounds()`（默认尺寸 + 主屏工作区底部居中 + 写回 AppSettings）+ `Persist()`。
- 窗口按钮组第三个按钮（FontIcon E7A7）→ `ResetWindowBounds()`。
- 托盘 `NotifyIconControl`：锁定项后加 `MenuFlyoutItem x:Uid="IconResetDesktopLyrics"`（FontIcon E7A7）→ 同上；6 语言 resw 加 `IconResetDesktopLyrics.Text`（重置桌面歌词窗口）。

## 4. 按钮改默认样式
`ControlPanel` 三个按钮去掉 `CornerRadius="14"`、自定义 `Background`、固定 Width/Height/Padding，改用默认 Button 外观 + FontIcon。

## 5. 独立设置（字号/字体/颜色/描边 + 设置页 Expander）
- **新设置字段**（SaveSettings + AppSettings + 映射）：`DesktopLyricsFontSize=36`、`DesktopLyricsFontFamily="Segoe UI"`、`DesktopLyricsColorRgb=0x00FFFFFF`（白，存 RGB uint 同 LyricsCustomColorRgb 模式）、`IsDesktopLyricsOutlineEnabled=true`。
- **渲染器**：`IDesktopLyricsRenderer` 增加 `void SetStyle(DesktopLyricsStyle style)`；新增 `DesktopLyricsStyle` record struct（FontSize/FontFamily/Color/Outline）。`TextBlockLyricsRenderer` 删除 `LyricsFontSizeBus`/`LyricsSettingsBus` 订阅（不再跟随主歌词设置），`SetStyle` 应用字号（不再 ×0.8）、字体、颜色；描边开关控制 4 向阴影层 Visibility。窗口 ctor 调 `SetStyle(Manager.GetCurrentStyle())`。
- **Manager**：`GetCurrentStyle()`（从 AppSettings 组装，RGB 逆运算为 Color）+ `RefreshStyle()`（推送到活动窗口）。
- **AppViewModel.Settings.cs** 新增 4 个 TwoWay 绑定属性（`DesktopLyricsFontSize`/`DesktopLyricsFontFamily`(FontInfo)/`DesktopLyricsColor`(Color)/`IsDesktopLyricsOutlineEnabled`），setter 内写 AppSettings + `SaveSettingAsync()` + `DesktopLyricsManager.RefreshStyle()`（沿用 `LyricsCustomColor` 模式）。
- **MusicDatabaseService.GetSettingsAsync**：映射 4 个新字段 + 用 `FontFamilyList` 把字体名匹配成 FontInfo 赋给 VM（照抄 AppViewModel.FontFamily 的加载写法）；`SaveCurrentSettings` 回写。
- **SettingsPage.xaml**：歌词 Expander（~1457 行）之后插入"桌面歌词"Expander（header 复用 `x:Uid="IconDesktopLyrics"`），四行标准布局（`Grid MinHeight="52" Padding="58,8,44,8"`）：
  - 字号：`NumberBox`（Min 10 / Max 200，TwoWay 绑 VM）
  - 字体：`ComboBox` + `FontComboboxTemplate` + `FontFamilyList`（照抄歌词字体行）
  - 颜色：`controls:ColorPickerButton SelectedColor TwoWay`（照抄自定义歌词颜色行，无开关）
  - 描边：`TextBlock` + `ToggleSwitch MinWidth="0"`
- **resw ×6** 新增 4 键：`DesktopLyricsFontSize.Text`/`DesktopLyricsFontFamily.Text`/`DesktopLyricsColor.Text`/`DesktopLyricsOutline.Text`（桌面歌词字号/字体/颜色/描边 + 各语言翻译）。
