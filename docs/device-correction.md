# 按输出设备应用卷积校正

在音效设置的「卷积校正」区域开启「按输出设备应用校正」。关闭时沿用原有全局校正；开启后，未绑定的设备旁路卷积，其他音效不受影响。

## 设置绑定

1. 在输出设备列表选择具体设备，或选择「当前实际输出（自动识别）」。后者需要已经开始播放，以取得实际输出端点。
2. 编辑曲线或导入 WAV。
3. 点击「绑定当前校正」。已有绑定时按钮为「更新绑定」。

每台设备保存独立快照。编辑草稿不会自动更新绑定；使用「载入校正」取出已有快照编辑，然后「更新绑定」保存。「解除绑定」后，该设备在设备模式下不再应用卷积。暂时离线的已绑定设备仍出现在列表中，可以编辑或解除绑定。最多保存 64 个设备。

卷积总开关、手动 / 自动前置增益、均衡器、响度和平衡继续使用全局设置。绑定只替换曲线 / WAV 的卷积参数。DoP、原生 DSD 和位流保持原有 DSP 旁路规则。

## 自动匹配

- WASAPI 使用实际打开的 MMDevice 端点 ID；默认输出不是一个独立的绑定目标。
- ASIO 使用驱动 CLSID，不用可能变化的枚举序号。
- 默认设备变化、设备恢复、独占或 ASIO 回退到共享输出时，在开始渲染前按最终端点重新匹配。
- 共享输出更换设备时清除原设备的滤波历史；新曲线加载失败不会继续使用上一台设备的校正。
- 曲线试听限定于开始试听时的实际设备，关闭编辑器后恢复绑定。

设备绑定随应用设置保存。绑定集合通过独立、互斥保护的配置邮箱传给播放进程，避免超过普通 IPC 命令的 2 KB 限制。实际输出 ID 随 DSP 状态通知给界面。

## 验证

`dotnet run --project _tools/PlaybackSwitchRegression -- --test-device-corrections`

覆盖稳定标识、全局设置保留、未绑定旁路、配置快照读写、解除绑定、默认输出匹配、ASIO 回退、试听隔离、旧滤波清理和状态协议兼容。

完整播放回归包含以上检查：`dotnet run --project _tools/PlaybackSwitchRegression`。

主程序和 `Player/AudioPlayer.exe` 必须一起更新；DSP 状态邮箱已升级版本。
